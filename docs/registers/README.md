# Registers

Acceptance-gate records generated from the code, the catalogue and a cited test run (BRD lines 124-126, 4807, 4812, 4813). Generated by `db/registers/generate.ts`; do not edit these files by hand. They describe the cited run, **Run 35, Run 35 web**, not the code as it stands today.

| File | What it is | Now |
|---|---|---|
| [verification-register.md](verification-register.md) | One row per FR, BR, DQ, CI and ZT with its disposition | 190 of 250 Pass; the rest say why not |
| [access-matrix.md](access-matrix.md) | Each permission's positive and negative test | 299 of 299 have both |
| [schema-constraint-register.md](schema-constraint-register.md) | Every column's constraints and the mechanism behind them | 3521 columns |
| `evidence/` | The tests these files cite, with the hash of the run they came from | |

To regenerate after a full run:

```powershell
$env:HRMS_ACCESS_TRACE_DIR = 'C:\somewhere\trace'   # optional, and the only way to fill the access matrix
npx vitest run --reporter=json --outputFile=C:\somewhere\run.json
npx tsx db/registers/generate.ts --results C:\somewhere\run.json --label "Run NN" --access-trace C:\somewhere\trace
```

The Coverage Log is a separate record with its own statuses (Documented, Restricted, Not reachable), and is not here.
